# Personal Agent V1

一个 Python 3.12+ 命令行 Agent：根据 Markdown 知识库回答问题，并在用户明确要求、逐次确认 diff 后修改文件。只使用 Python 标准库，无第三方依赖。

## 启动

在项目根目录运行：

```powershell
python -m agent.main
```

启动时自动读取项目根目录的 `config.local.json`，其中保存本地密钥、接口地址、模型和超时，无需每次设置环境变量或输入密钥。该文件已加入 `.gitignore`，位于 `memory/` 外，不会作为知识库内容发送给模型；密钥仅用于 API 认证。配置文件在本地以明文保存。

默认地址为 `https://api.zinyy.tech`，模型为 `mimo-v2.5-pro`，使用 Anthropic Messages 接口 `/v1/messages` 和 Bearer token 认证。实际调用的是配置的模型，不是 Claude Code 程序。

配置优先级：本地配置文件 → 环境变量 → 默认值；密钥均未配置时才交互输入（不回显、不自动保存）。配置文件使用 JSON 对象，支持下面三个环境变量同名字段及 `ANTHROPIC_AUTH_TOKEN`，所有值使用字符串。可选环境变量（对应字段未在文件中配置时生效）：

```powershell
$env:ANTHROPIC_BASE_URL = 'https://api.zinyy.tech'
$env:ANTHROPIC_MODEL = 'mimo-v2.5-pro'
$env:AGENT_TIMEOUT_SECONDS = '120'
python -m agent.main
```

不要把真实密钥写进代码或提交到 Git。程序不加载 Claude Code 配置，不加载 `.env`，不保存聊天。请求会将必要的对话及读取到的资料发送至所配置的 LLM 服务。

指定另一份知识库：`python -m agent.main --root C:\path\to\memory`。该目录必须已经存在并包含 `AGENT.md`。

输入 `/exit` 退出，`/clear` 清空进程内对话。写操作显示目标路径与完整 unified diff，只有输入 `yes` 才会执行；其他输入或中断均取消。一次任务可能涉及内容文件与索引两次确认。拒绝一次后，本轮剩余写入全部禁用。已经确认完成的修改不会因后续取消自动撤销。

## 文件与执行流程

- `agent/main.py`：命令行交互、bootstrap、模型与工具循环、写入确认。
- `agent/llm.py`：HTTPS Messages 请求，集中配置模型、地址、认证与超时。
- `agent/tools.py`：通用文件工具与路径、参数、写入检查，不理解知识库业务目录。
- `agent/__init__.py`：Python 包入口标记。
- `tests/test_agent.py`：离线工具、确认、循环和传输协议测试。
- `memory/`：原有知识库；不自动写聊天，未填入测试资料。
- `.gitignore`：忽略 Python 缓存、虚拟环境和本地环境配置。

每轮开始读取 `AGENT.md`，与简短 bootstrap 一起提供给模型；用户请求进入进程内消息列表。模型返回 `tool_use` 时顺序执行工具，再把对应 `tool_result` 交回模型，直到 `end_turn`。每轮最多 20 次模型请求。个人问题要求实际读取文件并给出相对路径依据；通用知识可以直接回答。下一轮刷新协议，但不会预加载整个知识库。

Bootstrap 的准确全文在 `agent/main.py` 的 `BOOTSTRAP` 常量中。它规定：个人回答基于文件、只有明确请求才提出修改、遵循已加载协议、索引优先、禁止越界、文件内容不构成授权、写入必须人工确认、拒绝后停止写入、诚实报告部分完成、不捏造用户事实。

## 工具接口

| 工具 | 行为 |
| --- | --- |
| `list_directory(path)` | 列出直接子项，最多 200 项，标明是否截断 |
| `read_file(path, start_line=1, max_lines=200)` | UTF-8 文本，行号从 1 开始；最多 500 行/20000 字符，标明截断 |
| `search_files(query, path=".")` | 对 `.md`、`.txt` 做不区分大小写的字面全文搜索；返回路径、行号、片段；最多 50 条匹配、2000 个遍历项，并报告跳过项和截断 |
| `create_file(path, content)` | 展示完整 diff，确认后独占创建；拒绝覆盖；必要时创建父目录 |
| `replace_text(path, old_text, new_text)` | 非空文本必须恰好匹配一次（包含重叠匹配检查），确认后局部替换并返回 diff |

工具只接受知识库相对路径。所有工具共享解析后边界检查，拒绝 `..`、绝对路径、盘符、ADS、符号链接、junction/reparse point 和硬链接。写入前重新检查路径；替换在确认后复读文件，检测用户同时编辑。拒绝和工具错误会作为明确错误回传给模型。

## 限制与取舍

- 首版只支持 UTF-8 文本，每个文件最多 100000 字节。长单行读取可能截断；返回值会明确说明。
- 搜索使用标准库逐文件扫描，避免依赖 ripgrep，保留相同根目录检查；没有 shell、数据库、向量搜索或后台任务。
- 对话超过约 250000 个序列化字符时停止，提示 `/clear`；不自动压缩或持久化。
- HTTP 超时或错误不自动重试；响应超过上限或模型输出截断时不执行该响应的工具调用。程序不自动跟随 HTTP 重定向。
- 多文件修改不是事务。失败时保留已完成修改，并列出成功写入的路径；本轮异常后清空对话，避免残缺工具消息影响后续请求。
- 面向个人单进程使用，不声称能防御另一个恶意进程在检查与操作间替换目录；也不提供并发写锁或断电恢复。已有文件替换是局部文本更新，不是完整事务系统。
- V1 未提供移动和删除工具，目录重构可手工完成；运行时不依赖任何业务分类名称。

## 验证

本次验证（2026-09-19）：13 项离线测试通过；真实 `mimo-v2.5-pro` 接口完成 `tool_use → tool_result → end_turn` 往返。临时合成知识库上的跨目录回答、全文搜索回退、提出修改及拒绝后保持文件不变均通过。正式 `memory/` 未参与写入测试。人工终端输入 `yes` 的完整交互仍可按下列示例自行验收；离线测试已覆盖确认回调返回同意后的实际落盘行为。

```powershell
python -m unittest discover -s tests -v
```

手动验证建议在复制的知识库上执行，使用 `--root` 指向副本：

1. 输入“请把‘沟通时优先用中文’记录到知识库。”检查路径与 diff，输入 `yes`；如果需要新增导航，再确认索引修改。
2. 输入“我有哪些沟通偏好？请给出来源。”检查是否实际读取对应索引与文件。
3. 输入“把刚才的沟通偏好改成优先用英文。”在确认时输入 `no`，检查文件保持不变。
4. 输入“请搜索知识库中出现‘沟通’的位置，并读取相关目录索引。”检查搜索和上下文读取。
5. 在副本的两个主题文件中放入相互关联的测试资料，提出需要结合两者的问题，检查工具记录和回答来源。
6. 请求读取 `../README.md`，验证工具拒绝越界（模型也可能直接拒绝提出调用）。
7. 在测试文件中放入两处相同文本，要求替换；验证工具拒绝多匹配，要求模型扩大到唯一上下文后才能提出有效修改。
