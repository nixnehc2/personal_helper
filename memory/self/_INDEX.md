# 用户当前状态

这里保存用户自身当前的背景、偏好、目标、价值观、工作习惯和约束。需要了解“用户现在是什么情况”时从这里查找。

## 内容导航

- [email_style.md](email_style.md)：已确认的稳定邮件写作风格。

- [basic-info.md](basic-info.md)：用户的基本个人信息，包括姓名等。

有实际信息时按自然主题新增或更新文件，并在这里添加导航，不预设固定模板。

过去的经历和状态变化见 [history/](../history/_INDEX.md)；具体项目见 [projects/](../projects/_INDEX.md)；外部对象见 [entities/](../entities/_INDEX.md)。未确认推断不应直接成为用户事实，统一在 Temporary Transaction 中修改，提交时经过用户确认与 self 额外审阅。
