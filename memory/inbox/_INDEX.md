# 待整理信息

这里是新信息的缓冲区，用于暂时无法确定归属、含义或确认状态的内容。

## 内容导航

- [email/](email/_INDEX.md)：不可变原始邮件归档，处理后保留；通过邮件解析器阅读。

- [inbox.md](inbox.md)：集中保存待整理内容，目前为空。新内容优先追加到此处，不为每条信息单独建文件。

## 使用说明

内容不默认视为已确认的长期事实。记录推断时明确标注，并在有依据时说明来源和背景。可能有长期价值但已能形成候选判断的内容优先进入 [pending/](../pending/_INDEX.md)；确认含义与归属后，优先整理到已有主题文件，移除已转存的重复内容或保留简短去向链接。

正式归属可从[根索引](../_INDEX.md)查找；不再活跃但值得保留的资料见 [archive/](../archive/_INDEX.md)。
