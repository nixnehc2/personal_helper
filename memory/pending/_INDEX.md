## 使用说明

- 新候选先检查本目录、相关正式分类和当前 Temporary Transaction，避免重复创建。
- 一个相关主题优先合并到一个文件；后续证据、限定条件和否定信息直接更新原候选。
- 候选成熟后，在统一 Temporary Transaction 中迁移到 `self/`、`history/` 或其他合适的正式分类，并删除对应 Pending。
- 不使用出现次数阈值自动转正；由 Agent 根据语义判断是否稳定、具体、长期有用且与已有 Memory 不冲突。

正式分类见[根索引](../_INDEX.md)；暂时无法判断归属或含义的新信息见 [inbox/](../inbox/_INDEX.md)。
