# Personal Knowledge Base

这是 Personal Agent 的长期知识库，使用普通 Markdown 和目录组织。读取和修改前先了解 [AGENT.md](AGENT.md) 中的协议。

## 内容导航


- [self/](self/_INDEX.md)：用户自身的当前状态，包括背景、偏好、目标、工作方式和约束。回答“用户现在是什么情况”。
- [entities/](entities/_INDEX.md)：具体外部实体，包括人、公司、学校、组织和地点。围绕某个具体对象查找时进入。
- [areas/](areas/_INDEX.md)：长期持续、没有明确完成条件的生活或责任领域。
- [projects/](projects/_INDEX.md)：具有明确目标或结束条件的事情。查找某个项目的方案、进展或决策时进入。
- [knowledge/](knowledge/_INDEX.md)：可以跨项目复用的知识、理解、推导和学习笔记。回答“是什么、如何理解”。
- [history/](history/_INDEX.md)：过去发生的事情与变化过程。回答“何时发生、为何变化、过去是什么状态”。
- [pending/](pending/_INDEX.md)：可能有长期价值但尚不够稳定或明确的候选记忆。后续持续修正，成熟后迁移到正式分类。
- [inbox/](inbox/_INDEX.md)：暂时无法确定归属或含义的新信息，不默认视为已确认的长期资料。
- [archive/](archive/_INDEX.md)：已经不活跃但仍有保留价值的资料。涉及旧项目、旧方案或历史追溯时再进入，默认不优先搜索。

## 查找指引

进入区域后先读取其索引，再选择相关文件。一个问题可以跨多个区域查找；无法定位时按协议使用文件名或全文搜索。

具体资料以各区域索引为准。以上目录是当前组织方式，可按实际内容调整，变更后同步维护本索引。
